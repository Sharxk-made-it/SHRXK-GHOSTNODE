Optional: drop ONE monospace font here (.ttf or .otf) and GHOSTNODE will use it
automatically on every PC (it is loaded by the process only, never installed).

Good fits for the cyberdeck look (check each font's licence before bundling):
  - Share Tech Mono
  - JetBrains Mono
  - Chakra Petch / Rajdhani (not monospace, but very "industrial")

If this folder has no fonts, GHOSTNODE falls back to the first available of:
Share Tech Mono, JetBrains Mono, Cascadia Mono, Consolas, Lucida Console, Courier New.
