# Changelog

## 0.2.0 — Toolkit expansion
- Replaced the company credit with creator credit `SHRXK` only.
- Added an original animated boot splash with a geometric glitch mark.
- Implemented System Inspector, File Vault, Hash Generator, Password Generator, Network Info, Quick Notes, File Utilities, Wi-Fi Recon, offline Packet Analyzer, Network Mapper, Digital Forensics, Password Audit and Hex Viewer.
- Added terminal commands `hashfile`, `wifi-scan` and `pcap-summary`.
- Added local helper tests and updated packaging dependencies/documentation.
- Wi-Fi module reports nearby networks and opens native Windows Wi-Fi settings; it does not crack or bypass protected networks.
- Packet Analyzer is offline classic-PCAP only; Network Mapper uses local host details and the existing ARP cache, without active probing.
